# ORAKUL AI

AI-powered football match analysis platform.

Live service: https://orakul-ai-jet.vercel.app

## About

ORAKUL AI analyzes football matches and provides probabilistic estimates (match outcome probabilities) through a web interface.

## Tech Stack

- **Next.js** — application framework
- **React** — UI
- **TypeScript** — language
- **Supabase** — backend

## Security

- Never commit secrets or API keys.
- Use environment variables for all sensitive configuration.
- Do not expose internal data or credentials in client-side code.

## Project Status

This repository is a work in progress. Features and stability may change.
